# QuizPortal (GitHub Pages + Google Apps Script)

## Files Included
- `Code.gs` — Google Apps Script backend (Google Drive storage & CSV export)
- `index.html` — Student Portal (Registration, Upcoming Quizzes, Shuffled Timed Quiz Engine, Results & History)
- `admin.html` — Admin Dashboard (Login, Stats, Registered Students, Quiz Management, Attempt Drill-down)
- `style.css` — Responsive stylesheet

## Quick Setup
1. Open your Google Apps Script project and replace `Code.gs` with the included `Code.gs`.
2. Click **Save**, then **Deploy → Manage deployments → Edit (pencil) → Version: New version → Deploy**.
3. Upload `index.html`, `admin.html`, and `style.css` to your public GitHub repository.
4. Enable **GitHub Pages** in repository **Settings → Pages** (`main` branch, `/ (root)`).
